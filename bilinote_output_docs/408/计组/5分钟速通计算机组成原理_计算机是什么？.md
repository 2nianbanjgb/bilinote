## 从算盘到二进制

![](./5分钟速通计算机组成原理_计算机是什么？/screenshot_000_6b5ec491-a610-408e-9971-afd5b1db5618.jpg)

## 二进制的物理实现
[原片 @ 00:18](https://www.bilibili.com/video/BV11b1UBoEGF?t=18)
![](./5分钟速通计算机组成原理_计算机是什么？/screenshot_004_b7519913-2202-4e7b-80b7-a5cbc1e9a556.jpg)
![](./5分钟速通计算机组成原理_计算机是什么？/screenshot_005_6121c547-a054-4642-a470-c691eed49546.jpg)
![](./5分钟速通计算机组成原理_计算机是什么？/screenshot_006_07aa0849-a356-48a2-9d46-42e5239e99be.jpg)
![](./5分钟速通计算机组成原理_计算机是什么？/screenshot_007_c4192922-5a67-453e-908d-c9e7bfcac506.jpg)
* **二进制的基础**：二进制只有 \(0\) 和 \(1\)。
* **物理硬件映射**：利用开关的“断开”与“闭合”两种状态，加上灯泡的“不亮”与“亮”来表示。
  * 开关断开、灯不亮，表示 \(0\)。
  * 开关闭合、灯亮，表示 \(1\)。
* **位宽与表示范围**：
  * 2个开关可以表示 \(2^2 = 4\) 个二进制数字，对应十进制的 \(0\)、\(1\)、\(2\)、\(3\)。
  * 3个开关可以表示 \(2^3 = 8\) 个数字。
  * 4个开关可以表示 \(2^4 = 16\) 个数字。
* 至此，利用开关和灯泡成功实现了**二进制表示法**。

## 逻辑门与加法器
[原片 @ 00:42](https://www.bilibili.com/video/BV11b1UBoEGF?t=42)
![](./5分钟速通计算机组成原理_计算机是什么？/screenshot_008_df74b7ff-4ea8-4957-a249-2beb61148a91.jpg)
![](./5分钟速通计算机组成原理_计算机是什么？/screenshot_009_a16f49cf-d4d5-437c-81ef-ba05a6d7fd49.jpg)
![](./5分钟速通计算机组成原理_计算机是什么？/screenshot_010_479bc1db-fe19-4240-9bf0-06a0142226af.jpg)
![](./5分钟速通计算机组成原理_计算机是什么？/screenshot_011_b819d015-6634-43ad-96db-be84ac05ca09.jpg)
* **布尔逻辑运算**：如何用二进制进行加减法？
  * \(0 + 0 = 0\)
  * \(0 + 1 = 1\)
  * 这对应了通过开关的**或逻辑（OR）**。
* **进位机制**：
  * \(1 + 1 = 10\)（即十进制的 \(2\)），需要进行进位，就像十进制中的 \(9+1=10\) 一样。
  * 进位对应**与逻辑（AND）**。
  * 本位对应**异或逻辑（XOR）**。
* **逻辑门电路**：将这些代表“与”、“或”等逻辑的电路称为**逻辑门电路**。
* **加法器**：将多个逻辑门组合起来，就能做成一个专门算加减法的电路，即**加法器**。

* **需求升级**：不仅需要加减法，还需要乘除法。
* **控制信号**：在加法器中加入控制信号，告诉电路执行什么运算。
  * 例如：输入 `00` 做加法，输入 `01` 做乘法等。
* **运算的本质转换**：
  * 减法本质上是加上一个负数。
  * 乘法本质上是多次加法。
  * 除法本质上是多次减法。
* 将这些电路组合在一起，发明了万能的运算电路：**算术逻辑单元（ALU，Arithmetic Logic Unit）**。

* **存储需求**：每次计算完的结果需要保存，不能每次都重新计算，需要能记住营业额的设备。
* **非门（NOT Gate）**：输入 \(1\) 输出 \(0\)，输入 \(0\) 输出 \(1\)。
* **记忆电路**：将两个非门首尾相连形成一个环。第一个输出 \(1\)，第二个输出 \(0\) 又反馈给第一个输入，从而实现稳定的状态保持。
* **寄存器（Register）**：将多个记忆电路组合在一起，就能存储多位数字，这就是**寄存器**。

* **自动化控制**：手动控制计算太麻烦，需要让装置根据指令自动控制自己。
* **控制器（Controller）**：增加一个新模块并加入控制线，让它发送控制信号指挥 ALU 和寄存器。
* **数据线**：连接 ALU 和寄存器，完成取数据、运算、存结果的过程。
* **CPU（Central Processing Unit）**：将控制器、ALU、寄存器封装在一起，便发明了**中央处理器**。
* **指令（代码）**：输入特定的指令（即代码），CPU 就能自动驱动内部模块工作，灵活完成不同的计算任务。

## 内存与寻址
[原片 @ 03:18](https://www.bilibili.com/video/BV11b1UBoEGF?t=198)

```python
寄存器（CPU内）
   ↓
Cache（CPU与主存之间）		← 【SRAM】在这里
   ↓
主存（内存）				← 【DRAM】在这里
   ↓
辅存（外存：硬盘、SSD等）
```

![](./5分钟速通计算机组成原理_计算机是什么？/screenshot_033_332dbc47-bd98-423e-a850-75ca0bb80ee1.jpg)
![](./5分钟速通计算机组成原理_计算机是什么？/screenshot_034_75906582-efe3-466b-a1f6-07a96daf5d60.jpg)

* **容量瓶颈**：CPU 内部的寄存器太少，只能存几个数字，无法存储大量数据。
* **内存（Memory）**：在 CPU 外部做很多个寄存器，给每个寄存器**编号**。
* **寻址**：需要哪个数据，就去对应编号的寄存器去取，从而解决存储容量问题。

## 总线系统
[原片 @ 03:48](https://www.bilibili.com/video/BV11b1UBoEGF?t=228)
![](./5分钟速通计算机组成原理_计算机是什么？/screenshot_039_e2facd82-f173-4887-9156-f40b2fc764ae.jpg)

![](./5分钟速通计算机组成原理_计算机是什么？/screenshot_041_974037a0-07c1-455b-b12f-4127e6d061f1.jpg)

* **连接部件**：所有部件（内存、CPU、I/O 系统）之间需要传递数据和控制信号。
* **电子高速公路**：设计用于连接所有部件的线路，即**总线（Bus）**。
* **三类总线**：
  * **数据总线**：专门传输数字内容（数据）。
  * **地址总线**：专门指定存储位置（地址）。
  * **控制总线**：专门传输操作指令（控制信号）。
* 所有部件共享这三套线路，即**总线系统**。

* 从最基础的二进制开关开始：
  * 用逻辑门构建了**逻辑门电路**。
  * 组合成**加法器**，并扩展成**算术逻辑单元（ALU）**。
  * 加上**寄存器**存储数据。
  * 用**控制器**协调工作，组成 **CPU**。
  * 通过代码让 CPU 执行不同任务。
  * 扩展**内存**解决容量问题。
  * 添加**输入输出系统**连接外部设备。
  * 用**总线**统一管理通信。
* 这套完整的架构，就是当今计算机的基础——**冯·诺依曼架构（Von Neumann Architecture）**。
